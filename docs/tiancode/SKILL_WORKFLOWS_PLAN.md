English | [中文](SKILL_WORKFLOWS_PLAN.zh.md)

2. Discover TianCode workflows only from the application-specific `skills/` directory (the repository root during development). Disable preset discovery of generic project/user `.agents/skills` for Desktop. Installed builds seed a writable TianCode-specific skills directory; add/edit/remove changes refresh More and subsequent Skill loads.
3. Supply nine complete report templates and nine separately invocable Skills: country brief, country hotspot, organization brief, organization research, hotspot event, country monthly review, organization monthly review, annual review and email. Each category owns its template file and records factual sources, periods, analytical confidence and missing inputs.
4. Add police and enterprise PPT skills with offline template resources, preview and editable PPTX output. Retain the two supplied police decks. Reuse Gorden MIT source with attribution; its restricted visual assets stay in the supplied reference directory, while enterprise decks use original business and Internet-company layouts.
5. Verify public installation popularity and repository sources, then expose focused PDF processing, document formatting, policy research, collaborative writing and internal communication Skills alongside existing office workflows. Record dated evidence and reuse the installed Office environment.
6. Test metadata rejection, filesystem add/edit invalidation, catalog transport, dynamic category selection, draft preservation and UI lifecycle. Exercise real Loader composition, keyless recorded-session output and browser behavior in both themes and narrow viewports.
7. Build TianCode and run aggregate compiler checks, targeted tests, lint, documentation and the requested Python checks; inspect the running Desktop and update current state, package guidance and verification records.

Work remains in the current workspace to retain the upstream synchronization and existing uncommitted customizations. The scoped pre-change archive is `.artifacts/skill-workflows-20261028/before.tar.gz`.
