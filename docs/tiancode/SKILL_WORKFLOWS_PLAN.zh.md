# TianCode Skill 工作流方案

[English](SKILL_WORKFLOWS_PLAN.md) | 中文

1. 从 Skill 文件向会话目录发布经过校验的本地化入口元数据，将目录失效通知转发到客户端，保留草稿、附件与命令保护，移除组件中固定的四类模板及生成指令。
2. TianCode 业务技能只从软件专属 `skills/` 目录发现，开发时使用仓库根目录，Desktop 关闭 preset 对通用项目及用户 `.agents/skills` 的发现。安装版初始化可写的 TianCode 专属技能目录；新增、修改或删除文件后，“更多”及后续 Skill 加载自动刷新。
3. 为国别单篇、国别热点、组织单篇、组织调研、热点事件、国别月度综述、组织月度综述、年度综述和邮件提供九份完整模板及九个独立可调用 Skill；每类自有模板文件，明确事实来源、统计周期、判断依据和缺失输入。
4. 提供公安及企业 PPT 技能，配套离线模板资源、预览与可编辑 PPTX 交付，保留提供的两份公安模板。Gorden 的 MIT 源码保留署名后复用，受限视觉素材保留在原参考目录；企业汇报采用原创商务与互联网企业版式。
5. 核实公开安装热度和仓库来源，在现有办公流程之外提供 PDF 处理、公文排版、政策调研、协同写作和内部简报技能，记录带日期的证据，并复用已安装办公环境。
6. 测试元数据拒绝、文件新增与修改失效、目录传输、动态分类选择、草稿保留和界面生命周期，验证真实 Loader 组合、无密钥录制会话输出及浅深主题、窄窗口浏览器行为。
7. 构建 TianCode 并运行聚合编译检查、定向测试、lint、文档及要求的 Python 检查，查看实际 Desktop，更新当前状态、包说明与验证记录。

工作保留在当前工作区，以延续上游同步及已有未提交定制；本次范围的修改前备份为 `.artifacts/skill-workflows-20261028/before.tar.gz`。
