# TianCode Skill 分类实现方案

[English](SKILL_CATEGORIES_PLAN.md) | 中文

输入框上方依次展示八个类别：对话、PPT汇报、公文写作、编报生成、数据分析、执法办案、格式校对和其他。类别持续可见，在窄窗口中换行，点击后展开可用 Skill 菜单。

1. 在经过验证的 `metadata.tiancode` 与 Session Skill 目录中增加可选分类标识：`chat`、`ppt`、`document`、`report`、`data`、`law`、`proofread` 或 `other`。保留双语标签、父级关系和排序，拒绝无效分类标识。
2. 按功能为全部应用内置 Skill 分类。显式元数据决定自定义分类，父级元数据提供继承分类。升级后通过内置名称保留既有 Skill 的分类，保留用户拥有的 Skill 文件；未分类的自定义 Skill 显示在“其他”。
3. 将前四个固定快捷项与“更多”替换为全部八个分类菜单。选中 Skill 时保留已写需求和附件，更新可见的斜杠调用；普通对话选项移除调用前缀。保留输入锁定、命令保护、提供方筛选、目录刷新和可见的获取失败恢复操作。
4. 验证元数据拒绝、完整内置分类、旧安装 Skill 元数据、分类覆盖、菜单选择和自定义 Skill 实时更新。在两种主题、390 像素与桌面布局中验证菜单关闭、草稿保留及八个类别完整显示。
5. 更新双语 Skill 编写指南和当前开发状态。运行相关单元测试、Skill 调用记录回放、编译构建、lint 和文档检查，完成独立的规格与质量审查。
6. 推送包含离线插件市场和分类改动的已验证分支。以新构建版本触发现有 TianCode Windows Actions 工作流，检查运行状态与安装器验证，下载安装包并核对 SHA-256 和构建提交后交付产物。
