# TianCode 上游同步方案

[English](UPSTREAM_SYNC_PLAN.md) | 中文

同步目标为本地官方 `dsh-v0.2.1-rc.3` 源码包，共同上游基线为 `dsh-v0.2.0-rc.2`。已提交的 TianCode 定制与工作区已有的办公入口改动均参与三方合并。

1. 保存工作区文件与 Git 树标识，使用临时索引计算合并，保留当前分支和真实索引。
2. 同步官方新增、修改、删除的文件、测试、依赖、迁移及升级指南，保留 TianCode 身份、素材、离线策略、数据目录、发布流程和办公资源。
3. 对照新服务接口处理桌面启动、打包、客户端注册与办公技能冲突，再生成派生目录。
4. 安装声明的依赖，运行 TianCode 构建、单元测试、录制会话回放、浏览器检查、lint、文档检查和 Python 检查。
5. 在[同步报告](UPSTREAM_SYNC_REPORT.zh.md)中记录实际验证与限制，并更新[当前状态](../state.zh.md)。

原始 ZIP 保留在 `version-history/`。解压源码通过相对符号链接保持原路径可访问，实际存放在忽略的 `.artifacts/upstream/` 中，避免文档递归扫描嵌套仓库。

同步前备份与合并元数据保存在 `.artifacts/upstream-sync/20261028/`，备份排除了被忽略的凭据及构建产物。
