
# TianCode（天山智码）企业内部版定制开发任务

## 一、项目背景与目标

当前已经克隆 DeepSeek Harness 官方源码：

- 项目目录：`~/python_projects/hz_project/deepseek-harness`
- 源码仓库：`https://github.com/deepseek-ai/deepseek-harness`
- 基础版本：`dsh-v0.2.0-rc.2`
- 原始版本标签：`dsh-v0.2.0-rc.2`
- 目标操作系统：Windows 10/11 x64
- 使用环境：企业完全隔离互联网的内部局域网
- 使用范围：公司内部，不对公众发布

**核心目标：**

基于现有 DeepSeek Harness Windows 桌面应用，开发一款名为“天山智码（TianCode）”的企业内部 AI 编程助手。

保留原有 AI Agent、代码生成、代码修改、文件操作、终端命令执行、会话管理、项目管理及模型配置等核心功能。

主要完成软件品牌替换、安装身份定制、离线环境适配和 Windows 安装包生成。

**总体开发原则：最小化修改，保留现有架构，避免不必要的重构。**

请直接检查和修改当前项目代码。不要仅输出实现建议或伪代码。在具备环境和依赖的情况下，完成实际修改、测试与打包。

### 2.2 品牌视觉方向

品牌设计来源于新疆乌鲁木齐地区的天山、雪峰和冰川。

Logo 采用：

**天山雪峰 + 编程符号 + 简约几何构图。**

设计具体要求：

1. 使用几何化雪峰轮廓，突出天山地域特色。
2. 融入 `</>` 或 `< >` 等代码视觉元素。
3. 图标整体采用现代、简约、专业的软件设计风格。
4. 不使用复杂风景照片、骆驼、人物、建筑及旅游装饰。
5. 不保留 DeepSeek 原有鲸鱼标志。
6. 避免繁杂纹理和过度渐变，确保小尺寸清晰。
7. 应用图标不能包含中文或英文文字。
8. 欢迎界面可以采用图形 Logo + TIANCODE 的完整品牌组合。
9. 应用图标采用圆角方形设计，提供透明背景源文件。
10. 应确保深色和浅色系统主题下均有足够对比度。

### 2.3 标准色彩


| 色彩     | HEX       | 用途               |
| ---------- | ----------- | -------------------- |
| 天山深蓝 | `#0F2742` | 图标背景、主要视觉 |
| 冰川蓝   | `#4FC3F7` | Logo、交互强调     |
| 浅冰蓝   | `#AEEBFF` | 高光与辅助元素     |
| 雪山白   | `#F4FAFF` | 雪峰及浅色背景     |
| 深灰蓝   | `#1E2E3E` | 文字与辅助界面     |

设计可以使用轻微蓝色渐变，但不应该造成小尺寸辨识度下降。

### 2.4 品牌资源生成

如果项目目录中尚未提供 TianCode Logo，请根据上述规范直接创建原创矢量 SVG 图标。

优先使用标准 SVG 图形、路径和几何元素生成，不依赖在线图像生成服务。

至少生成：

- TianCode 主图标 SVG
- Windows 使用的 1024×1024 PNG
- Windows 应用及安装器所需 ICO
- 系统托盘图标
- 浅色与深色适配版本

优先复用原项目现有的图标渲染与打包工具，而不是引入新的大型图像处理框架。

正式替换前，检查 Windows 原图标与托盘图标的实际文件路径及生成脚本。
