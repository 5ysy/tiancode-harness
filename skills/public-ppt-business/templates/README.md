# 国企商务模板

`template.pptx` 为原创12页、16:9（13⅓×7½英寸）可编辑模板，深蓝主色，白底内容页。文字使用系统字体 PingFang SC；无此字体时在任务副本中统一选择已安装的中文字体，并逐页预览。

| 页 | 页面用途 | 主要编辑内容 |
| --- | --- | --- |
| 1 | 封面 | 标题、报告期、单位与汇报人 |
| 2 | 议程 | 三个汇报板块 |
| 3 | 关键工作结论 | 工作结果、原因、后续动作 |
| 4 | 核心指标 | 三项数值、名称与口径 |
| 5 | 经营趋势 | 原生柱状图、嵌入工作簿、来源与单位 |
| 6 | 重点项目进展 | 原生表格，事项、进展、责任、验收 |
| 7 | 重点措施 | 三项任务与完成条件 |
| 8 | 风险与应对 | 原生风险表格 |
| 9 | 资源与预算 | 原生资源表格 |
| 10 | 工作计划 | 原生节点表格 |
| 11 | 提请研究决定 | 决策事项、依据影响、办理要求 |
| 12 | 结束 | 具体审议请求与联系人 |

`example.json` 覆盖全部文字标记，`charts` 示例更新第5页的图表及工作簿。示例包含待补充事项与标明的演示数字，供验证操作；正式汇报须基于用户材料完整改写。正文建议18–24pt，标题32pt，封面42pt；脚注11pt。每个正文块建议一至两行，表格每格建议两行以内。

共享生成器与资产使用范围见 [资源许可](../../public-ppt/ASSETS.md)，全部操作见 [工作流程](../../public-ppt/references/workflow.md)。
