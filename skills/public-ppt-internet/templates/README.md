# 互联网企业模板

`template.pptx` 为原创12页、16:9（13⅓×7½英寸）可编辑模板，靛蓝主色，深色封面与白底内容页。文字使用系统字体 PingFang SC；无此字体时在任务副本中统一选择已安装的中文字体，并逐页预览。

| 页 | 页面用途 | 主要编辑内容 |
| --- | --- | --- |
| 1 | 封面 | 产品、报告期、团队与汇报人 |
| 2 | 讨论事项 | 结果、证据、决策 |
| 3 | 目标结果 | 达成情况、用户变化、后续动作 |
| 4 | 北极星与护栏 | 三项数值、指标定义及样本口径 |
| 5 | 关键转化环节 | 原生条形图与嵌入工作簿 |
| 6 | 用户分层与留存 | 原生留存表格 |
| 7 | 实验记录 | 实验、样本周期、结论与后续动作 |
| 8 | 产品路线图 | 里程碑、交付内容、负责人、验收 |
| 9 | 产品技术依赖 | 团队、节点与阻塞影响 |
| 10 | 风险护栏 | 指标、触发条件与处理责任 |
| 11 | 资源决策 | 请求、成本收益依据与办理期限 |
| 12 | 讨论与决策 | 具体讨论事项与联系人 |

`example.json` 覆盖全部文字标记，第5页原生图表使用标明的演示数字100/60/35/12。正式交付前必须从材料替换所有演示数据和待补充项，或明确披露材料缺口。正文建议18–24pt，标题32pt，封面42pt；脚注11pt。每个正文块建议一至两行，表格每格建议两行以内。

共享生成器与资产使用范围见 [资源许可](../../public-ppt/ASSETS.md)，全部操作见 [工作流程](../../public-ppt/references/workflow.md)。
