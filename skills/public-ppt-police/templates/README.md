# 公安模板资源

| 文件 | 用户提供的原始材料 | 页数及尺寸 |
| --- | --- | --- |
| `police-report.pptx` | 公安警察工作汇报PPT模板.pptx | 28页，13⅓×7½英寸 |
| `police-case.pptx` | 公案类.pptx | 28页，13⅓×7½英寸 |

两份文件保留全部图片、分组、文字、母版与作者来源信息。视觉主题相近，文件内容存在差异；选定模板后使用该文件对应的槽位清单，避免混用地址。具体来源路径和完整性哈希见 `assets.json`。

## 页型地图

| 源页 | 用途与选用建议 |
| --- | --- |
| 1 | 封面：主题、副题、概况、汇报人与日期 |
| 2 | 目录：四个板块，随实际主题改写 |
| 3 / 9 / 15 / 21 | 四个章节过渡页，章节序号和概述需同步 |
| 4 / 5 | 概况、重点任务与图文说明 |
| 6–8 | 分组图形与年份示意，检查图片中固定内容 |
| 10–14 | 案件或专项工作内容页，替换全部样例数值和英文 |
| 16–20 | 专项工作、对照与示意页，检查百分比及图片内数据 |
| 22–26 | 部署、计划与图文说明，核对原图里的演示数值 |
| 27 | 结束页：汇报主题、概述与汇报人 |
| 28 | 作者及来源信息，保留为附录 |

先渲染拟用页再确定布局。没有原生图表的图片示意不能用于展示新统计数据；需要数据图时新增可编辑原生图表与嵌入工作簿。当前源文件的分组和文字可编辑，图片中的内容保持图片形式。沿用源字体，替换字体时检查所有页面。

`police-report.inventory.json` 与 `police-case.inventory.json` 提供全部页面的形状ID、段落索引和文字运行，可用共享脚本 `inspect` 重新生成。`example.json` 为 `police-report.pptx` 的12页严格文字编辑示例，填充后保留材料缺口提示，不构成真实案件或工作数据。

脚本与命令见 [工作流程](../../public-ppt/references/workflow.md)，使用范围见 [资源许可](../../public-ppt/ASSETS.md)。
