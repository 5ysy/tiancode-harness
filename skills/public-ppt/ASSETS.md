# PPT资源与使用范围

`public-ppt-business/templates/template.pptx`、`public-ppt-internet/templates/template.pptx`、两个示例JSON及 `scripts/` 为本项目原创资源。模板由 `create_templates.py` 生成，使用原生文字、表格及图表，没有外部视觉模板、图片或字体文件。字体名称为系统字体引用，使用方需具备对应字体的合法使用权；字体替换须检查全部页面。

`public-ppt-police/templates/police-report.pptx` 与 `police-case.pptx` 分别完整复制自用户提供的 `docs/tiancode/materials/gongan/公安警察工作汇报PPT模板.pptx` 与 `公案类.pptx`。保留全部28页、作者及来源信息。用户提供文件不构成开放许可或商业授权；使用方应核对原作者授权和单位使用权限，保留模板署名及来源页。资产哈希记录在公安技能的 `templates/assets.json`。

参考材料 `docs/tiancode/materials/GordenPPTSkill-main` 的代码许可为MIT，视觉模板与预览受单独限制，包含禁止营利组织内部使用和商业再分发。本技能没有复制其中的代码、PPTX、预览、插画或装饰素材，不将该项目的代码许可用于解释视觉素材授权。本技能脚本为独立实现，无外部更新或下载功能。
